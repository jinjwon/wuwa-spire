# 배경음 넣는 법

이 폴더에 아래 이름으로 mp3를 넣으면 장면에 맞춰 반복 재생돼요. 없는 파일은 조용히 건너뛰어요.

| 파일 | 재생 장면 |
|---|---|
| `title.mp3` | 타이틀 · 캐릭터 선택 |
| `map.mp3` | 지도 · 사건 · 휴식 · 상점 |
| `battle.mp3` | 일반·정예 전투 |
| `boss.mp3` | 명식 보스전 |
| `win.mp3` / `over.mp3` | 승리 / 패배 |

일시정지 메뉴에서 배경음을 켜고 끌 수 있어요.
직접 구매·보유한 음원을 개인 플레이용으로만 넣어 주세요. 음원 파일은 저작권 때문에 저장소에 올리지 않도록 `.gitignore`로 막아 뒀어요.
