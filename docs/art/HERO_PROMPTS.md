# 공명자 이미지 생성 프롬프트

마지막 갱신 2026-11-12. 끝난 프롬프트는 이 문서에서 지운다(이전 내용은 git 기록에 있다). 규격과 검수 항목은 [ART_PIPELINE.md](ART_PIPELINE.md), 설정은 [CHARACTER_BIBLE.md](../lore/CHARACTER_BIBLE.md)를 따른다.

## 공통 첨부
모션 시트는 2장, 카드 시트는 3장을 순서대로 첨부한다.
1. 공식 이미지 (아래 표)
2. 모션은 `art/source-v2/hero_mor.png`(승인된 7등신 비율 기준), 카드는 그 캐릭터의 새 `hero_<id>.png`
3. 카드만: `art/source-v2/cards_hiy.png`(카드 화풍 기준)

## 남은 작업
| 캐릭터 | 저장 파일 (`art/source-v2/`) | 공식 이미지 |
|---|---|---|
| 음림 | `hero_yin.png` | 전신 캡처 필요. 저장소에 없음 |
| 린네 카드 | `cards_lyn.png` | `lyn-official.webp` |
| 모니에 카드 | `cards_mor.png` | `mor-official.webp` |

## 전체 동작 시트 16칸 (한 번에 생성, 부드러운 모션)

캐릭터마다 GPT 생성 한 번으로 모든 동작의 중간 그림까지 받는다. 한 장에 함께 그려야 크기·얼굴이 맞는다.
- 크기: **세로 1024×1536**, 4열×4행 16칸. 칸이 세로로 길어 캐릭터 키가 약 270px(게임 몸 208px보다 커서 줄여도 선명).
- 첨부: 1. 공식 이미지(위 표) 2. 그 캐릭터의 지금 시트 `art/source-v2/hero_<id>.png`(외형·도트 기준).
- 결과: 보드 키 `hero_<id>_full`에 넣고 고르면 `art/source-v2/hero_<id>_full.png`가 된다. 이 파일이 있으면 `prepare-heroes-v3.cjs`가 8칸 시트 대신 이것을 쓴다(명령 한 번에 전원 처리).
- 게임 재생: 대기 2장 숨쉬기(1초), 공격 [시작·준비·휘두름·베기×3·휘두른 뒤·회수] 16fps(베기 약 190ms), 막기·피격·시전·해방 각 8장 16fps.
