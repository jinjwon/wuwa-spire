# 명조 전투 시스템 → 덱빌딩 이식 분석 (2026-11-06)

출처: 공개 위키·가이드(Fandom Concerto Energy, IGN Combat Guide). 게임 클라이언트 분석은 하지 않음(약관·안티치트).

결론: 핵심 루프(협주→변주→해방→공진)는 이미 갖춰졌다. **속성 7개 중 응결·전도·기류만 고유 효과가 없다**는 점이 가장 큰 빈칸이다. 이 세 속성 카드는 지금 "그냥 피해"라서 속성 덱을 짜는 재미가 약하다.

## 2. 설계안 (슬더스식 규칙으로 번역)

규칙 원칙: 슬더스처럼 **숫자가 눈에 보이고, 턴 단위로 정산**되고, 기존 `applyElem` 한 곳에 추가.

### A. 응결 — 「서리」 (방어형 · 슬더스 '약화' 계열)
- 응결 공격 시 서리 +1. 서리 3 → **빙결**: 적의 다음 공격 피해 −50% 후 초기화.
- 재미: 큰 공격 의도(예: 관통 17)를 보고 서리를 맞춰 끊는 판단.

### B. 전도 — 「과부하」 (연쇄형)
- 전도 공격 시 과부하 +1. 과부하가 있는 적이 맞을 때마다 **다른 무작위 적**에게 과부하 수치만큼 연쇄 피해(관통). 적 턴 종료 시 1 감소.
- 재미: 다수전에서 한 놈에 쌓아 두고 연타로 번개 연쇄.

### C. 기류 — 「풍식」 (누적형 · 슬더스 '독' 계열)
- 기류 공격 시 풍식 +1. 적 턴 시작마다 **풍식 수치만큼 피해**, 이후 수치 유지(감소 없음), 단 공진 파괴 시 풍식 2배 폭발 후 0.
- 재미: 장기전 보스용. 공진 파괴 타이밍과 맞물림(명조 기류 서포터 감각).

### D. (선택) 아웃트로 연계 강화
- 협주 3칸 교체 시 들어오는 공명자의 **첫 카드 비용 −1**. 교체 리듬(명조의 핵심 손맛)을 덱빌딩에서도 보상.

## 3. 구현 범위 (고른 것만)
- 코드: `applyElem`에 분기 3개 + 적 상태 표시(`stc`) + KW 툴팁 + 적 턴 정산 1곳.
- 연출: 기존 `pop`/`vfx` 재사용(응결=하늘색 링, 전도=보라 tracer, 기류=녹색 spark).
- 검증: `scripts/selfcheck.cjs`에 속성별 1개씩 체크 추가.
